# 🚀 Mon API

Une API REST développée avec **Node.js**, déployée sur GitHub Pages.

## À propos

**mon-api** est un serveur API construit en JavaScript pur avec Node.js. Elle expose des endpoints REST accessibles via HTTP.

## 🌐 URL de l'API

```
https://slahdada.github.io/mon-api/
```

## 📁 Structure du projet

```
mon-api/
├── index.js          # Point d'entrée du serveur
├── package.json      # Dépendances et scripts npm
├── package-lock.json # Verrouillage des versions
└── .gitignore        # Fichiers ignorés par Git
```

## ⚙️ Installation

### Prérequis

- [Node.js](https://nodejs.org/) v14 ou supérieur
- npm

### Cloner et installer

```bash
git clone https://github.com/slahdada/mon-api.git
cd mon-api
npm install
```

## ▶️ Démarrer le serveur

```bash
node index.js
```

Le serveur démarre et est accessible sur `http://localhost:3000` (ou le port configuré).

## 📦 Scripts disponibles

```bash
npm start       # Démarrer le serveur
```

## 🛠️ Technologies utilisées

- **Node.js** — environnement d'exécution JavaScript
- **JavaScript (ES6+)** — langage principal
- **npm** — gestionnaire de paquets
